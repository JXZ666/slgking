黄油之王 **0.27.0**：Windows 正式版、已上线的网页更新，以及 Android **0.27.0-a2 测试版**。三端变化分别如下。

## 一、Windows 客户端 v0.27.0

### 改进

- 「更新游戏数据」统一更新 SLG 大类、DLsite 或全部目录；SLG 大类包括 Dikgames、F95 等资料。封面按需下载，失败重试并入更新流程。
- 本地库新增「自动找游戏根」，支持在合集目录中寻找多款作品，逐款预览确认；继续保留多路径扫描、手动添加、待处理重试与路径修复。
- 细化 RPG Maker、Unity 等引擎线索，并增加 WOLF、LiveMaker、Bakin 组合识别。利用配置标题、编号、启动程序及多语言别名辅助匹配，不运行游戏或脚本。
- 对未匹配作品可主动查询 DLsite／VNDB，核对后保存资料，方便离线再次识别。「更换封面」支持联网查找候选，确认保存才替换个人封面，并可恢复默认。

### 修复

- 减少卸载程序、配置重置和存档工具等辅助 EXE 对游戏名称识别的干扰；证据不足或冲突时保留人工确认。
- 改善浅色模式文字与收藏夹展开操作，保留本地错误日志入口。
- 防止关闭窗口、取消查询或切换账号后的迟到结果覆盖当前封面；失败保留旧图。

### 代码与兼容

- 正式更新资产为 `slgking.exe`，版本 0.27.0。已验收新库及六种旧库升级，个人记录保留；引导种子不含个人资料。
- 引擎识别不代表所有游戏存档都已适配；本次没有新增存档备份功能。

## 二、网页端 0.27

[打开网页端](https://slg-king.com/m/#/)。**网页已公开更新，无需安装。**

### 改进

- 新增 SLG 大类、DLsite、全部目录切换；DLsite 支持游戏名、RJ 编号、开发者检索及语言、作品形式筛选，原生评分独立展示。
- 首页采用分页目录，上下均有翻页入口；来源、排序和页码保留在链接中，从详情返回恢复浏览位置。
- 新增云端积分榜与装扮榜，原站资料和 DLsite 官方商品页入口移到详情标题附近。

### 修复

- 修复 DLsite 标签显示编号的问题：优先显示已审中文名称，未知标签不猜测含义；标签筛选仍使用原始编号。
- 补齐不同来源的评论与论坛游戏身份解析，避免同名作品混淆；网页与客户端同一 RJ 作品共用公开评论。
- 改进快照异常、缺封面和详情返回处理，保留旧 SLG 链接。

### 数据边界

- 网页使用公开目录快照，不触发外站实时采集。个人云记录仅本人可见，不自动同步 Windows／Android 本机私人记录。

## 三、Android 测试版 v0.27.0-a2

**APK 尚在测试，可能存在问题，欢迎反馈。** 本节包含相对公开 0.26.0-a1 的累计更新。

### 改进

- 新增 SLG 大类、DLsite、全部目录，支持语言／作品形式筛选、原生评分与按需封面；更新所选目录或依次更新全部，保留主动停止及各目录结果。
- 「追踪」分为 **版本更新／想玩／收藏夹**，分别显示计数、加载和重试；详情返回与旋转保留分区和滚动位置。「我的记录」保留自建资料、分类与网址管理。
- AI 翻译新增 DeepSeek、硅基流动、Kimi、智谱 GLM、通义千问、OpenAI 及自定义选项；选择公司与模型后填 API Key，接口自动填充，高级设置可手动修改。免费翻译保留，旧配置不会因打开页面自动替换。
- 图标更新为黄油方块与王冠，目录和关于页显示作者头像；详情支持打开经过校验的官方来源链接。

### 修复与兼容

- API Key 输入默认遮罩，不回显已保存原文；相同目标留空保留旧 Key，换公司或实际接口需要新 Key。取消不写入，保存与翻译互斥。
- 追踪页使用独立列表与请求状态，防止重复已读操作及迟到响应覆盖；改善大字体、横屏及键盘下的表单滚动。
- 保持原包名与官方签名；已在 x86_64 Android 9 环境验证 a1→a2 覆盖升级保留资料。0.26→a2 已通过历史数据库兼容测试，未进行实际 APK 降级再升级验证。
- Android 7.0 及以上，包含 arm64 与 x86_64，不含 32 位 ARM；arm64 真机及完整应用内下载安装链仍待验证。Kimi／GLM 预置保留兼容型号，不承诺是最新模型。
- 感谢群友 **vegetable dog** 为 Android 移植作出的贡献。

- 本项目不托管或分发游戏文件。提交反馈时请遮住账号密钥、API Key、私人路径及备份内容。
