# 黄油之王网页端 0.28.0 源码

正式网页已于 2026-10-20 上线：[打开黄油之王](https://slg-king.com/m/#/)。一般用户直接使用网页，无需运行本源码包。

本包包含实际发布的网页和共享 HTTP 服务源码。`SOURCE_MANIFEST.json` 记录 67 项生产回读文件的 SHA-256，以及补齐的官网、管理员静态资源和许可证来源；原有运行源码均保持发布时字节。本包没有复制 Git 历史、服务器配置、账号库、私人记录、令牌或密钥。

## 从 0.27 更新了什么

- 公开评论增加折叠追评，展开后分页查看，也可以回复原评论或某条追评。
- 独立消息页集中展示公告、活动和回复；可定位讨论并标记已读。
- 评论作者和排行榜昵称可查看公开名片；可控制装扮与寄语是否公开。
- 统一“黄油之王”名称、黄油王冠图标和“头衔”用语。
- 改善切换账号、登录失效、草稿隔离和迟到响应处理；减少追评重复查询和无关请求。

SLG/DLsite/全部目录、每页 20 款、中文标签和两种排行榜来自 0.27，本版继续保留。RJ/VJ 与官方封面兼容代码不代表 VJ 资料已经首发，也不代表外站采集已经恢复。

## 本机预览

使用 Python 3.10 或更新版本。普通 HTTP 服务及本机预览使用 Python 标准库；`requirements-server.txt` 中的 `pywebpush`（包含其 `cryptography` 依赖）只用于可选管理员推送。采集图片核验另需 Pillow，但不属于本包预览所需功能。网页源码没有 npm 安装步骤。

在源码目录运行：

```bash
python tools/local_preview.py --port 8080
```

然后打开 `http://127.0.0.1:8080/m/#/`。启动器使用操作系统临时目录，在 SLG 分区生成一款明确标为合成的演示条目；DLsite 分区因没有数据而提示不可用。它只绑定回环地址，正常停止后清除演示状态。演示不包含真实用户或线上目录，不进行采集、同步、真实登录或付费接口请求。浏览器可能因图标、统计或尚未配置的账号接口产生本机请求，这些请求只到预览服务。

普通 HTTP 预览只适用于静态页面、合成目录和匿名阅读；网页账号读写需要受信任反向代理提供的 HTTPS。它不能代替生产账号验收。

如已有自己合法准备的公开目录和独立数据目录，可使用原服务入口：

```bash
python serve_catalog.py --port 8080 --publish-dir /path/to/publish --data-dir /path/to/data
```

原服务绑定所有接口；请在隔离环境或防火墙保护下运行。需要 HTTPS 时自行配置受信任的反向代理，并审阅服务的传输来源校验。不要让代理信任来自公网任意客户端的转发头，不要直接复用正式站点的 Cookie、账号库或密钥。公开目录必须符合服务的快照及哈希校验格式，不能把私人数据库放进发布目录。

## 组件边界

- 本包提供已上线网页及共享 HTTP 服务，不提供 DLsite/F95 的独立采集执行器、桌面采集器程序、定时任务、生产部署脚本或业务数据。保留的管理员/bridge 适配源码在执行采集时需要另行配置对应组件；不要在本包中启动采集任务。
- `slg_account` 是桌面端惰性依赖，服务器共享规则具有明确的缺失回退。生产源码库存中也没有 `slg_dlsite_vendor`、`slg_collector_reviewed`、`slg_maintenance`；本包不创建空模块或补入其他版本。
- 发布服务启动只恢复任务计划分派器，不代表包含采集执行器。演示启动器不调用这段计划恢复流程。
- 网页读取不可变公开快照，不会在浏览时抓取外站。新增官方封面可以采用设备直连地址，既有服务器封面保留兼容回退；真实 VJ 目录与新官方索引首发仍待单独验收。
- 云端账号、积分和公开评论共用；Windows/Android 本地私人记录不随登录自动同步，网页个人云记录也不自动与它们同步。
- 追评沿用审核和限流，不奖励积分，不提供追评点赞或编辑。隐私开关控制装扮和寄语，不隐藏昵称、公开正文或榜单分数。
- 本次没有新增抽奖、兑换码、补签道具、帮助中心或本地游戏扫描/启动管理。

## 验证与限制

发布前已完成 329 项回归、48 个隔离 HTTPS 浏览器场景，以及上线后 360/390/430/1280 四种宽度的匿名只读检查；另有一项因 Windows 符号链接权限跳过。发布源码的 67 项哈希已与冻结候选核对。

隔离测试不等于真实生产账号写入、iPhone Safari 实机、真实客户端升级链或外站图片可达性证明。本地负载结果也不能用来承诺生产承载人数。
