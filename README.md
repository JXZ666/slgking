# 黄油之王 0.29.0 · Windows 源码

这是正式版 `slgking.exe` 对应的客户端源码。构建来源和原始文件校验和见 `SOURCE_MANIFEST.json`。

使用带 Tcl/Tk 的 Windows Python 3.13。在虚拟环境中执行 `python -m pip install -r requirements.txt`，然后运行 `python slg_main.py`，或用 `build_exe.bat` 构建 `dist/slgking.exe`。在不同环境重新构建时，EXE 哈希可能不同。
