电脑与手机的私人资料

Windows 和 Android 的评分、状态、收藏、私人备注与自建分类保存在各自本机，不随账号自动同步。电脑扫描到的路径与启动程序留在电脑。

游戏文件不会上传。个人资料备份可能包含本机路径，请私下保管；导入前先导出当前资料。

云端账号与公开内容

三端可以使用同一个账号。昵称、云端积分、头衔、签到记录和装饰跟随账号使用，游戏公开评论共用；网页论坛是独立讨论区。

主动公开发表的内容会上传，可能展示昵称、头衔与装饰。私人记录仍留在本机。

三端可以用同一个账号吗？收藏会同步吗？

三端共用云端身份、积分、签到与公开评论。Windows 和 Android 的评分、收藏及私人记录不自动同步，需通过备份迁移；网页暂不提供这套私人游戏库。

iPhone 应该使用哪个入口？

使用网页端即可。Android APK 无法安装到 iPhone，目前没有 iOS 安装包。

Android 安装失败或遇到问题怎么办？

请确认设备支持 Android 7.0 及以上和 arm64 或 x86_64；32 位 ARM 不受支持。当前 APK 为测试版，可能存在问题。

提交问题与复现步骤 ↗

反馈可附手机型号、Android 版本和截图；请勿公开登录密钥、恢复码或私人备份。

账号遗失后可以找回吗？

登录密钥和恢复码请自行保存；遗失后无法找回，账号不能通过邮箱重置。 新设备登录需要登录密钥和恢复码。换设备时请选择“登录”，重复创建账号会生成另一份身份。

电脑与 Android 的私人资料怎样迁移？

评分、收藏、私人记录与自建分类不会随登录自动同步。Windows 和 Android 可通过个人资料备份迁移；Windows 入口为“更多工具… → 备份与恢复…”。

导入可能覆盖已有记录，并清除备份未包含的记录。请先导出当前资料。个人备份不含账号登录密钥与恢复码，可能含本机路径，请私下保管。

Windows 客户端会发送哪些使用统计？

软件会发送随机生成的安装标识、客户端版本、启动平台、游戏条目数，以及少量功能事件和汇总数字，用于了解版本使用情况。该标识不由硬件信息或云端账号生成；统计不含本地游戏目录、私人评论正文或游戏文件。

这里可以下载游戏文件吗？

不可以。黄油之王 是目录检索、评论与本地管理工具。本站不托管游戏文件，也不提供游戏文件下载或资源获取渠道。

没有网络，还能使用吗？

Windows 在首次更新目录和封面后，可离线搜索、筛选与浏览本机资料。网页需要联网；客户端的云端账号、公开评论及目录更新也需要联网。
